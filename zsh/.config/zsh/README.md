# Zsh quick reference

## Search and navigation

- `Ctrl-R`: fuzzy command history
- `Ctrl-T`: fuzzy file picker inserted into the current command
- `Option-C`: fuzzy directory jump
- `z <name>`: jump to a frequently used directory
- `zi`: interactively choose a known directory
- `fe`: fuzzy-find a file and open it in Neovim
- `fif [query]`: ripgrep, preview, and open a match in Neovim
- `croot`: jump to the current Git repository root
- `mkcd <dir>` / `take <dir>`: create and enter a directory

## Daily commands

- `l`, `ll`, `la`, `lt`: clean directory views
- `b`: bat
- `lg`: lazygit
- `gs`, `ga`, `gc`, `gp`, `gd`, `gl`: focused Git shortcuts
- `reload`: restart the login shell
- `zshconfig`: edit the Zsh entrypoint
- `nvconfig`: open the Neovim config
